# 行っていること
私は今、「選定AI」というAIエージェントの開発を行っています。

## 背景

私が働いているユニフォームネクストでは、お客様の課題やこだわりに応じたユニフォームの選定や提案を行っています。
現在、ありがたいことに事業が成長しており、この提案も増えてきました。
提案専門のチームを持っていますが、人数が少なくリソースの限界を感じています。

## AIの導入
今までも、Notebook LMを用いた選定業務改善は行っていました。
しかし、Notebook LMはRAGのようなイメージで、条件の中から商品を選ぶようなユースケースでは適しません。

そこで、条件による商品検索や自律的な判断を求め、AIエージェントに載せ変える話が出てきました。
ちょうど別の案件でもBedrock AgentCoreを使用していため、私が携わらせていただいて選定AIの話が進みました。
