# 背景
## 題材
私は今「選定AI」の開発を行っています。

弊社ユニフォームネクストは、業務用ユニフォームの販売を行っています。
ミッションとして「ワークライフをハッピーに！」を掲げており、お客様の働くを幸せにするため日々行動しています。

さて、そんなユニフォームネクストでは、お客様の課題やこだわりに応じたユニフォームの選定や提案を行っています。
この提案なのですが、事業拡大に伴い量が急増しており、提案を行っているチームのリソース限界が見受けられました。

すでに提案チームの方々が、昨今流行りのAIを用いてリソース限界を緩和しようと試みていました。
具体的には、Notebook LMに商品データや在庫データなどを読み込み、提案してもらうという内容でした。

しかし、Notebook LMはあくまでナレッジ検索。商品の選定は不得意なのでなかなかうまくいきませんでした。

そこで、システムGも積極的に関与し、より良い改善を行おうと「選定AI」の開発を始めました。
